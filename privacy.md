# Privacy Policy

_Last updated: October 26, 2026_

**rclone-sirius** is a personal OAuth client used exclusively by its owner
to synchronize their own Google Drive files with their personal computer
via [rclone](https://rclone.org).

## Data accessed
The application accesses only the Google Drive files of the account that
authorizes it, solely to read, upload, update and delete files during
synchronization.

## Data storage
Files are transferred directly between Google Drive and the owner's local
machine. OAuth access tokens are stored only in the owner's local rclone
configuration file. No data is stored on any external server.

## Data sharing
No data is collected, sold, or shared with third parties.

## Google API Services
The use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.
